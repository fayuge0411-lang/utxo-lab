# 比特币 UTXO 互动实验室

一个可在浏览器中直接运行的中文教学模拟器，用交互实验理解 UTXO、交易签名和节点验证。

## 使用方法

下载本仓库后，用浏览器打开 `index.html` 即可，无需安装依赖或启动后端。

## 四个经典实验

- **篡改收款人**：签名后修改交易内容，观察签名快照校验失败。
- **合法转账**：支付 0.6 BTC，获得 0.199 BTC 找零，并支付 0.001 BTC 模拟手续费。
- **重复花费**：再次引用已经消耗的 UTXO，观察交易被拒绝。
- **盗用小王的币**：用自己的模拟签名尝试花费小王的 UTXO，观察授权检查失败。

在“自由模拟交易”中，可以选择输入、收款人、签名身份、付款金额和手续费，再进行签名、篡改和验证。点击“重置”可恢复初始账本。

## 思考题

为什么“重复花费”和“签名不匹配”都能导致交易失败，却检查的是两种不同条件？

前者检查输入引用的输出是否仍未花费；后者检查授权是否绑定当前交易内容。此外，模拟器还检查签名身份是否满足输入的花费条件。

## 模拟边界

本项目不连接真实区块链，不使用真实 BTC 或私钥。签名通过交易快照比较模拟，不执行 secp256k1 / ECDSA 运算；交易 ID 也是模拟标识。真实比特币还涉及脚本、序列化、内存池、工作量证明与共识等机制。
